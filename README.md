# Rui Yang — Portfolio Website

A responsive, no-build portfolio for GitHub Pages. The visual direction is a
minimal editorial layout adapted for business and financial analytics.

## Files

- `index.html` — website content and section structure
- `styles.css` — layout, colors, typography, and responsive styles
- `script.js` — mobile navigation and photo fallback
- `assets/profile-placeholder.svg` — replace with your professional photo

The existing Python environment files are retained for the course setup and are
not required to display the website.

## Personalize before final submission

1. Add a professional portrait to `assets/`, then change the image path near
   the About section of `index.html` (JPG recommended).
2. Replace the LinkedIn `#` and placeholder email near the bottom of
   `index.html`.
3. Replace each project placeholder with your own title, description, tools,
   image, and project link as work becomes available.
4. Review the education and experience wording for exact dates and titles.

## Publish

Commit these files to the `main` branch of `RuiYang0622.github.io`. GitHub Pages
will serve the site at <https://RuiYang0622.github.io>.
